# 实验区

`labs/` 保存单一机制、可复现、可丢弃的代码。实验不得成为发布项目的依赖。

每个实验需满足：

- 问题可以用一次实验回答。
- 环境和输入固定。
- 执行前记录预测。
- 结果由日志、测试、断点或产物证明。
- 失败结果与成功结果同样保留。
- 敏感数据经过删除或替换。

## 目录边界

- 只放自研的最小实验、靶场源码和实验产物；不把整份上游源码复制到这里。
- 外部源码、参考快照和归档放在 `workbench/upstreams/`。
- 研究结论和设计文档放在 `docs/`；成熟的用户工具放在 `projects/`。
- 历史 `src/` 仅用于迁移尚未归类的材料，不作为新代码入口，也不作为发布项目依赖。

计划实验见[实验索引](../docs/learning/lab-index.md)。
