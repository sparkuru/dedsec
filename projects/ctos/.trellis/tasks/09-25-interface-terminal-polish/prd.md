# 界面与终端可用性整理

## Goal

统一 ctOS 的视觉层级与信息密度，使连接数据和终端在窄屏、软键盘和大字号下仍可读、可操作。

## Background

- `lib/main.dart` 自定义卡片与 `lib/device_page.dart` 默认 Card 并存；连接页呈现原始 `ss` 文本，终端固定多行控件占空间。
- 依赖兄弟任务 `09-25-trustworthy-state-workbench` 的视觉基线；开始本任务前复核其已交付 token 和组件。

## Requirements

- R1：统一表面、状态色、字级与间距，保留现有深色/薄荷色身份；大屏控制阅读宽度。
- R2：连接行先展示状态、地址、UID/应用，原始 `ss` 输出仍可查看；保持过滤和部分结果提示。
- R3：终端快捷键栏可收起，当前 App/Root 会话清晰，提供输出搜索/复制入口，保留 PTY 控制能力。
- R4：图标动作有可访问名称，触控目标、缩放字号、软键盘和安全区行为可验收。

## Acceptance Criteria

- [ ] 手机与大屏页面视觉一致，无明显横向溢出；大字号下主要动作可见。
- [ ] 连接可按原有条件检索，结构化行与原始文本内容一致，部分结果仍明确标识。
- [ ] 终端软键盘、快捷键栏、App/Root 切换、复制/搜索及 Ctrl-C 在授权设备上通过相关检查。
- [ ] Flutter 分析、测试和当前包所需的实机回归通过，未验收设备单独列明。

## Out of Scope

- 不在本任务引入后台终端、多会话持久化、命令脚本或网络服务。
