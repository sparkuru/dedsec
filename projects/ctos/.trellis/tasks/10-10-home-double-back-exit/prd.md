# APK 主页双返回退出到桌面

## Goal

避免在 APK 内部主页误按返回直接退出：第一次按返回留在应用内并提示“再按一次返回键退出”，连续第二次返回才退出到桌面。

## Background

- 2026-10-10 用户要求追加独立旁 task；2026-10-11 用户要求暂停另一任务并开始本任务，随后明确选择“四个主入口，2 秒”。授权本地实现、检查与构建，设备验收另行授权。
- 实施前源码基线：主页为 `lib/main.dart:34` 的 `Observatory`，四个主入口由 `lib/main.dart:602` 的同一壳层承载；二级页通过 `Navigator.push` 打开，基线主页尚无双返回退出处理。实施与实际检查见 `check.md`。
- 当前实现与生命周期边界见 [架构](../../../design/architecture.md)，本任务不依赖公共秘密库、TOTP 或 SSH 的交付，也不改变其任务状态。

## Requirements

- BACK-01：概览、信息、工作台和终端四个主入口的根路由均生效；第一次系统返回不得退出到桌面，显示“再按一次返回键退出”。
- BACK-02：第一次返回后 2 秒内第二次系统返回才退出到桌面；满 2 秒及之后的返回重新作为第一次处理。
- BACK-03：二级页、弹窗及软键盘按原有返回语义处理，关闭这些界面的返回不计作主页退出确认。
- BACK-04：切换主入口、打开二级页/弹窗/键盘或应用进入后台后，清除旧的待退出确认；重新回到可退出场景时需要重新确认。
- BACK-05：退出沿用既有 Android/应用生命周期，不强杀进程或附带新增的服务停止操作；公共认证、PTY、短任务与 HFTP 按其既有契约处理。
- BACK-06：2026-10-11 用户追加要求提示在下方出现；使用屏幕下方安全区域，并避开底部导航及同时可见的其他操作反馈。

## Acceptance Criteria

- [x] BACK-01：主页首次返回后仍可操作，提示文字可见，桌面未出现。
- [x] BACK-02：2 秒内再次返回后回到桌面；满 2 秒及超时后再次返回只显示提示，不退出。
- [x] BACK-03：从二级页返回主页、关闭弹窗及收起键盘均不触发退出提示或形成待退出确认。
- [x] BACK-04：提示后进入后台再回来，第一次返回仍只提示；离开确认场景再回来的行为相同。
- [x] BACK-05：退出及重新打开后无新增的生命周期回退；测试结果分别记录本地验证和获授权设备实测。
- [x] BACK-06：提示位于下方、底部导航上方；窄屏/横屏/大字及浮动 Snackbar 同时出现时不重叠，不误清其他反馈。

## Out of Scope

- 改变二级页导航、增加退出设置、强制停止进程、扩大后台服务能力。
- 未获本任务授权的安装或设备操作；本地检查不能替代 Android IME/返回手势/桌面实测。

## Confirmed Decisions

- 2026-10-11 用户选择“四个主入口，2 秒（推荐）”，主页覆盖范围与时长已收敛。
- 保留公共秘密库任务的现有成果和未完成关卡，本任务独立实施。规划/实现/验证分开记录。
- 用户反馈“实机验收过”，记录为上一轮交付的用户验收报告；设备/API/安装哈希未提供，不冒称 agent 实测。随后要求将提示移至下方，本轮直接实施该调整，退出行为不变。
