# SSH 客户端与公共认证集成设计

状态 planning；技术主体见 [父 SSH 设计](../10-08-ssh-terminal/design.md)，公共契约见 [App 公共认证](../../../design/app-authentication.md)。

依赖公共统一秘密库已验证契约，用 SSH adapter 进行身份绑定和受管凭据释放，不另建加密库或系统解锁流程。每次请求检查公共使用会话及限定连接操作，各跳 host key/远端认证独立；会话锁定/跨功能复用按已确认公共规则：前台共享，后台秒数可设置，锁屏/手动/进程重启锁定。公共认证不归 SSH 页面或客户端所有，不修改其他生产服务的策略。

其余客户端/config/输入/资源/风险决策引用父设计，避免复制后漂移。Q3 已确认后台保留连接、手动 Stop；独立 SSH 前台服务与重新附着设计见父设计。config 基础 TCP 转发已批准，随会话 Start/Stop；非 loopback 监听已选择连接前确认暴露范围；SSH 输入/↑/↓ 交远端、不追加程序逻辑及不设特定程序兼容验收已确认；config 不得绕过指纹核验已确认；整版规划待最终审阅，原生格式/平台可行性未实测。密文与私有数据的回退不得删除用户内容或绕过验证。
用户已选择将 Authenticator 主口令/便携库/设备快捷/迁移模型用于 SSH。已保存凭据可随加密库恢复；config/Include/私钥/关联公钥或证书/known_hosts 一并进入公共加密包；SSH adapter 负责引用/身份/信任与 native 临时访问适配，公共底座负责密文和一致事务。公共库锁定不主动关闭已完成远端认证的连接，后台保留不延长秘密会话。旧完整审阅状态失效，需共同重新审阅。
