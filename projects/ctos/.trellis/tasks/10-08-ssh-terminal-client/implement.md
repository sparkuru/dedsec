# SSH 接入实施计划

状态 planning；必须先完成公共统一秘密库子任务已验证格式/会话/设备快捷/迁移契约，再开始认证/凭据集成。父子关系不自动执行依赖。

执行主体清单与命令引用 [父实施计划](../10-08-ssh-terminal/implement.md)，顺序为 native OpenSSH 探针 → 私有配置导入/受约束求值 → 会话/认证桥/基础 TCP 转发 → 统一秘密库的 SSH adapter 接入 → UI/本机终端回归 → 当前授权设备验收。

集成额外验证：公共验证取消、锁定、不可用、过期、后台及迟到回调不能释放秘密；每跳 host key/身份绑定后才提供匹配凭据；连接结束使上下文失效。SSH 输入验证按父 R2/AC2 的字符/控制键/输出/窗口事件进行，不把本机历史截获套给 SSH，不建立特定远端程序兼容验收。父 AC1–AC9 和跨子任务验收全部映射至真实证据。

后台保留/手动 Stop 按父 R8、AC6 验证；父完整规划获明确实施批准前不得 task.py start；版本/许可证、资源初值及可行性关卡见父设计。依赖失败回到规划，不自动降级客户端或免验证。
统一模型变更后不重复实现 KDF/文件/快捷包装/迁移，不以 SSH-only 系统弹窗替代公共会话。补充混合库恢复、库覆盖旧代次、SSH 条目删除不影响 TOTP、快捷失效回主口令及已建立连接与库锁定分离验证；补充 config/Include/私钥/关联公钥或证书/信任完整包恢复、路径/引用闭包及覆盖冲突/信任审阅测试，并优先验证无明文磁盘的 native 临时访问适配；覆盖/导出接入公共 BASE-10 的重新输入与认证解密，验证来源包失败/损坏/不合规不得覆盖，已有目标另验证当前口令、空目标只验证来源，成功解密不跳过指纹审阅/连接核验；首版公共 BASE-11 更换主口令后验证 SSH 文件/身份/凭据关联不变、旧会话失效、新库新口令/旧备份旧口令及失败恢复，不更改远端秘密；接入公共 BASE-12 关闭前本次主口令认证解密，验证失败/取消保持旧状态，成功锁定/数据保留/旧快捷回调失效，已完成认证的 SSH 连接仍按 Stop 规则存续；SSH 密码/私钥口令输入及实际秘密展示接公共 BASE-13，验证安全窗口/任务预览、嵌套/迟到及返回普通输出页的保护释放；SSH 接入公共唯一秘密库设置页（BASE-15），验证首次创建/导入/解锁原业务返回、取消无半成品及设置与验证器一致，导航不改变 Stop/已建立会话；当前完整规划待共同最终审阅。

依赖基座公共合同及适用独立关卡审阅后，按任务授权做 SSH 集成，业务/native 依赖的联合 AC 在接入后验证，避免完整客户端与底座互相等待。native 加密文件内存读取/Include/ProxyJump 探针已前置做 Linux 研究，Android 和生产集成待执行；不需 TOTP 页面先完成。HOTP 特化已撤销，本客户端 task 仍 planning，当前没有真实设备或登录授权。
