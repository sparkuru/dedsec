## Goal

让使用者进入工作台后快速找到五项常用工具，以中文、分层参数完成任务，并直接读取、复制或保存所需结果。

## Requirements

- R1：五项常用工具前置，环境与临时文件管理降为次级入口；保留全部九项脚本及加载/重试/刷新，适度收紧列表间距。
- R2：已知工具参数和枚举显示中文，解释用途而非重复字符上限；密码默认只展示种子和长度，盐值/盐文件/字符集/必含字符可展开，长度用数字键盘及 1–128 校验。
- R3：编码工具明确选择文本或文件，仅提交所选来源；切换不丢失另一来源草稿。哈希不展示编码方向。文件区域与其他字段左对齐。
- R4：密码遮挡/显示及直接复制；哈希逐项复制；IP 字段摘要；转换及加密结果提供预览/文件名/格式化大小和保存文件。原始 JSON、JSON 保存保留为次级详情，未知结果可回退原始视图。
- R5：HFTP 状态前置，启动/停止主操作随状态变化；导入/清理属于共享库管理区，清理与主操作区分。保留手动启动、默认本机、后台、密码遮挡和通知停止。
- R6：保留深色/薄荷绿、Material 控件、48dp 触摸区域；375dp、横屏、大字号可滚动且无溢出。内部 script ID 放技术详情。

## Acceptance Criteria

- AC1 / R1：目录乱序时仍优先显示常用工具；全部入口、环境自检及文件管理可达。
- AC2 / R2–R3：中文仅改变显示，SDK 参数键/枚举/值保持原协议；折叠项仍参与提交；来源切换、哈希方向隐藏与文件取消有测试；文件来源未选择文件时提示并阻止提交，文本来源保留原有空文本语义。
- AC3 / R4：复制目标密码/哈希而非整个 JSON；默认及折叠原始视图不意外显示遮挡密码；输出 token 原样传给文件导出；JSON 导出保留完整协议。
- AC4 / R5：导航不启动或停止 HFTP；运行时能显式停止、未运行时可启动；清理仍需确认。
- AC5 / R6：窄屏/横屏/2倍字号/减少动画测试通过；运行/取消/超时/重跑及原有回归通过。
- AC6：Flutter analyze/full tests、Android lint、current APK 构建通过；实测与未验证项写入 design/task 检查。新包安装须本轮明确授权。

## Out of scope

不新增工具、算法、SDK 字段、搜索/收藏/历史、后台任务或全局主题系统；不改变 Root、SAF、文件配额、HFTP 认证/监听/生命周期及 Python 边界；不操作原始用户文件或清理已有共享库。

## 停止错误反馈回归（2026-09-27）

用户反馈完成打开、上传、下载后点击 App HFTP「停止」，错误立即出现。当前设备保留日志显示另一次启动的 `listener_bind (errno 98)`，不能据此把用户的停止操作等同于主动重启；同时发现日志区域运行时灰色错误块，返回后重新进入可恢复。

- R21：显式停止须立即建立停止边界，禁止旧 ready/failure/EOF 回调发布错误或重新进入 running。关闭完成前禁止再次启动或改配置；正常停止清除当前错误但保留诊断日志。失败清理期间不得复用旧 Service 覆盖 owned 资源。
- R22：真实 TCP 上传/下载、STOP、同一端口立即重启可连续执行；仅设置受检查的 SO_REUSEADDR，不允许抢占活跃监听器或修改全局 TCP/VPN/路由策略。旧版没有 reuse 的 TIME_WAIT 与新版连续重启结论须分别记录。
- R23：日志滚动、折叠/展开、清空/追加、停止及返回重进均不能触发页面构建异常；独立状态不能共用 PageStorage 标识。
- R24：追加实际连续验证发现的 Root 控制边界：先处理已排队的有效心跳，再判断同一10秒期限，不降低无心跳/EOF/owner/session退出限制。closed日志须包含固定allowlist原因，便于区分完成、idle和socket错误；屏幕关闭/恢复及大文件读回需实测，不能用一次重试成功抹去超时。
- R25：Root中继的App心跳需要在用户主动启动的前台文件服务期间可运行。仅该adapter持有App PARTIAL_WAKE_LOCK，最长沿用5小时会话限额，无续期；构造失败、停止、异常清理必须释放。普通App路径不取得此锁，屏幕可关闭，不要求电池豁免或修改系统/VPN策略；实机验证熄屏传输及停止后的锁回收。

追加验收：确定性 Java/Dart 竞态与状态回归、本地真实 TCP 连续重启及端口独占测试，最终包 TARGET-PHONE 隔离目录 LAN 多轮传输/停止/立即重启，保持用户当前配置/文件和 VPN 条件。已完成单周期验收作为历史证据保留，不代替本次反馈回归。
