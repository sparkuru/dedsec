# Authenticator TOTP 实施计划

状态 planning / 已确定范围整理完成，待最终审阅。当前仅规划，无代码/构建/设备授权；最新完整方案审阅后才可启动。

## Dependencies

先交付并验收 [统一秘密库底座](../10-08-app-authentication/implement.md)，再接入 TOTP；不依赖 SSH 客户端。共同初始化/设置/密文/快捷/迁移归底座，业务复用 BASE-01..15，不另建 KDF/库/解锁页。

## Ordered Work

1. 读取领域/公共契约与前端/host-bridge/日志规范，固定离线扫码实现/权限/许可证、标准 TOTP 参数校验与资源上限。基础 SHA-1/6 位/30 秒；不支持类型/参数拒绝，不扩大至未确认扩展。
2. 实现 TotpAdapter 条目/种子/生成/删除固定操作和已支持组合的 RFC 6238 向量、窗口/前导零/2038 后时间测试；无需真实种子。会话/consumer/entryId/代次检查与密文事务接公共底座。
3. 实现相机与系统所选图片的宿主离线解码/URI 校验/无种子确认投影，多码用户选择后提交；手动添加共用校验。字节/像素/候选/耗时有界，取消/权限拒绝/URI 失效/锁定/换代/迟到结果拒绝，临时内存/授权回收，原图不改。
4. 工作台加入 Authenticator 页面，接公共首次设置/导入/解锁/原业务返回和共同秘密库设置。条目管理/代码/倒计时/主动复制实现既定 UX；接入 BASE-13 敏感窗口及收敛后的 BASE-14 主动复制/敏感标记，不实现剪贴板清理及其设置/跟踪/探针，清理由用户自理。普通页面及已建立 SSH 不受导航影响。
5. 集成验证 BASE-08..15、混合 TOTP/SSH 备份恢复、错误/取消保护、首版改口令/旧备份语义、关闭快捷回主口令、跨业务会话与后台库超时、前后台时间变化、敏感呈现/主动复制边界。逐项映射 AC-01..11。
6. 在当前设备/服务账号另获授权后，做代表服务绑定/登录与混合库恢复，记录 APK/设备/API/ROM/来源/实测范围，更新 design/依赖/兼容/验证；未执行不标通过。

## Validation and Rollback

规划期检查 JSON/JSONL/链接/git diff --check。实现期按影响执行 ./hako flutter analyze、相关/全量 ./hako flutter test、Android lint/宿主测试及必要平台验证；具体测试路径随模块形成固定。真实 Keystore/窗口/剪贴板依赖公共平台证据但仍做业务集成，不以 mock 当设备通过。

风险是扫码/原图种子/业务权限与库代次，技术关卡失败回规划，不弱化加密或权限。回退只关闭新入口，保留混合密文库/SSH 数据/用户文件，不更改 Root/HFTP。HOTP 及其计数/发码/校准/恢复已撤销，其他平台迁移不实现。
