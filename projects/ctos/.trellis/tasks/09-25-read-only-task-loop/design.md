# 技术设计：只读任务与选择性导出闭环

## 已核对的现状

- 信息页接口来自 `NetworkSnapshot.collect` / `Collector.interfaces`，当前行以接口名作为稳定对象标识。
- Python 工作台已有静态注册表、参数校验、统一结果 envelope、App 执行来源、15 秒超时、取消和有界输出；`ScriptPage` 已显示运行状态与原始结果。
- Python 任务目前只收到设备快照，没有网络快照；结果没有持久历史。
- Android 文件保存已走 Storage Access Framework。原生层收到文件选择成功后才写内容，取消时不写文件。
- 当前总导出直接包含网络、设备和连接快照（排除应用图标），没有内容选择与导出前预览。
- 持久化规范要求先定义保留上限、清理、敏感数据和 schema 所有权；目前没有任务历史数据库。

## 方案与边界

### 接口诊断任务

将第一个对象任务作为静态注册的 `network.interface_diagnose` App 工作台脚本。接口详情页提供“诊断此接口”入口，并把选中的接口名作为只读上下文带入任务页；用户不需要再次输入。任务提交仍由用户明确触发。

执行时，原生 Python runner 为该脚本附加一次新的 `NetworkSnapshot.collect` 结果。采集沿用 Android App API 与现有来源字段，不申请 Root、不调用 shell、不发网络请求、不写设备配置。Python 只按完整接口名精确匹配本次快照；对象已消失或输入不合法时返回失败及可恢复说明，不换用其他接口、不把缺失数据当零。

结果复用现有 Python 工作台 envelope，保留状态、开始时间、耗时、App 来源、错误/超时/取消和数据上限。任务数据仅包含所选接口的名称、状态、MTU、地址、可用计数器、关联网络元数据、路由及采集时间。可读摘要只描述快照事实：例如接口状态、是否有地址、可用来源；不声称完成互联网连通性检查。原始所选数据可在结果页展开核对。

### 本地历史

持久历史仅接收 `device.info`、`memory.snapshot` 和 `network.interface_diagnose` 三个明确 allowlist 的只读任务，不自动保存密码、加密、文件、HFTP 或外部网络等可能含秘密/产生副作用的工作台结果。Android host 单独拥有版本化 JSON 文件和原子替换；Flutter 只经 MethodChannel 列取记录和清理。历史包含任务状态、时间、来源及结果；接口诊断只保存所选接口标识和结果，不保留完整网络快照、图标、未选择的快照类别或无关 Python stderr。

历史记录数与文件体积均有上限；达到上限时移除最旧记录。用户可以在工作台历史页查看记录并主动清空；清理前确认，失败记录保持失败状态。用户已确认最多 20 条/5 MiB、满额删除最旧记录、手动清理且不自动过期。

### 选择性导出

当前导出入口改为导出预览页。内容选择包括当前网络快照、当前设备快照、当前连接快照，以及历史页中用户勾选的接口诊断结果。每项先显示来源、采集时间和简要范围；预览只序列化所选块，保存按钮再调用现有 SAF JSON 导出。结果带 `exportedAt`，快照各自保留来源/时间；不含未选类别、应用图标或未经选择的其他历史记录。未选择内容时禁用保存；选择器取消返回未保存状态。

### 界面决策

2026-09-28 使用项目已有 UUPM 做原生 Flutter 设计系统、Flutter 栈与历史/清理交互检索，未生成或持久化额外设计系统文件。检索支持深色、高信息密度、状态可扫描的运维工具方向；同时命中 Material/Roboto、Flutter `LayoutBuilder`、Android 返回行为、破坏性操作确认和有内容的空状态等建议。

本任务保留 ctOS 既有深蓝暗底、薄荷绿主色和 Material 3，不引入 UUPM 返回的青紫/霓虹配色或营销页结构。接口诊断、历史列表和导出预览沿用工作台卡片与滚动页面：每屏一个主动作；状态同时用文字和图标表达；清理用独立危险动作并二次确认；无历史时给出回到接口列表的入口；图标按钮提供语义名称。小屏先单列，宽屏沿用现有 840 dp 阅读宽度，关键操作至少 48 dp 并适配大字号。

## 错误与状态

| 情形 | 结果 |
| --- | --- |
| 接口名无效或新快照中接口已消失 | `failed`，说明刷新接口列表后重试 |
| 接口为 DOWN、无地址、计数器不可用 | 任务仍为 `completed`，摘要明确描述观测值/缺失项，不推断数据为零 |
| 执行超时或用户取消 | 保留 `timed_out` / `cancelled`，不写成成功；若仍有 envelope 则写入同一有界历史 |
| 网络/设备快照采集失败 | 保留实际错误状态与来源信息，不构造成功的空结果 |
| 历史格式无效或读写失败 | 页面显示历史不可用/保存失败，保留可恢复操作；不静默覆盖为成功历史 |
| 导出内容未选择或用户取消系统文件选择器 | 不创建文件；只显示未保存/取消状态 |

## 风险与取舍

- 网络地址和路由属于本地敏感数据，所以历史按用户确认的严格上限只存所选对象，导出逐项 opt-in。
- App API 快照与接口列表当前可能来自已授权 Root 采集；诊断固定使用 App 来源的新快照，以免继承 Root 权限、引入额外授权或让来源不清楚。
- Python 当前 32 KiB 输入/结果限制维持不变；只传此任务所需网络快照并只保存单接口投影。
- Android 设备安装、Root 与 SAF 实机检查须在本任务重新得到明确设备授权后进行；既有设备验收不能视为本任务授权。
