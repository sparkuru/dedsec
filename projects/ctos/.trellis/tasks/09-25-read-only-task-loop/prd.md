# 只读任务与选择性导出闭环

## Goal

让用户从一个现有信息对象进入有上下文的只读任务，读懂结果，保留有界历史，并按需导出选定内容。

## Background

- 当前 `device.info` 与 `memory.snapshot` 只保留最后一次内存中结果，且以 JSON 为主；`lib/main.dart:227-263,609-676`。
- 依赖兄弟任务 `09-25-trustworthy-state-workbench` 的快照状态/来源表达；开始本任务前复核其实际接口。

## Requirements

- R1：选择一个网络接口作为首个纵向样例，携带接口标识进入参数受校验的只读诊断。
- R2：结果显示任务状态、开始时间、耗时、来源、可读摘要和原始内容；失败、超时、取消清晰可见。
- R3：增加有上限的本地历史和清理入口；敏感参数及保留策略在设计阶段明确。
- R4：导出前允许预览和选择包含的快照/结果，沿用系统文件选择器，不自动上传。

## Acceptance Criteria

- [ ] 可从接口详情执行任务并查看带接口上下文的结果，不需再次输入接口名。
- [ ] 重启后能查看有限条历史并主动清理；失败/超时/取消不伪装为成功。
- [ ] 导出只含所选内容，取消文件选择不写文件，含来源和时间。
- [ ] App/Root/Vector/PTY 权限和生命周期边界保持原状；Flutter 与授权设备的相关验证通过。

## Out of Scope

- 不提供任意 Shell 命令入口、远程服务或后台自动运行。
- 不在本任务扩展应用、进程、日志等完整对象图谱。
