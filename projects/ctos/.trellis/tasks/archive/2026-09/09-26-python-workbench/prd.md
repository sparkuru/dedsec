# Python 工作台与 SDK

按用户本轮要求实现：移除设备页的系统负载及对应 procfs 采集；原命令页改为工作台，原工作台改为概览；APK 内置 portable Python3；脚本 item 可进入二级页，具备参数、运行、取消、结果与导出；定义可扩展 SDK。用户随后明确要求终端也支持 python3，以及保留类似 Magisk ZIP 的 APK 内置运行包扩展能力；本版实现编译时包清单和逻辑挂载，curl 接入为文档示例，外部 ZIP 导入未授权也未实现。

验收：Python 不依赖 Termux、Root 或运行时下载；内置环境自检、设备摘要、内存快照、文本摘要；目录与表单来自统一注册表；参数在 Python 端再次校验；未知脚本不执行；单任务、15 秒超时、有界输出；二级页返回及 App 后台回收脚本进程；原网络与 PTY 不回退。

范围：arm64 Android APK 与源码、设计文档、检查记录。新增依赖用官方来源固定版本。用户已授权在 PLR110（192.168.9.9:44603）覆盖安装 current 和测试 APK并验收；未授权修改系统配置或提交已有 WIP。
