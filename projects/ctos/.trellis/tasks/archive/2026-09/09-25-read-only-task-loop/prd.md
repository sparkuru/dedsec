# 只读任务与选择性导出闭环

## Goal

让用户从一个现有信息对象进入有上下文的只读任务，读懂结果，保留有界历史，并按需导出选定内容。

## Background

- 当前 `device.info` 与 `memory.snapshot` 只保留最后一次内存中结果，且以 JSON 为主；`lib/main.dart:227-263,609-676`。
- 复用已归档的 [可信状态与工作台基础体验](../archive/2026-09/09-25-trustworthy-state-workbench/prd.md) 中现有快照状态/来源表达；以当前源码与实际接口为准。

## Requirements

- R1：选择一个网络接口作为首个纵向样例，携带接口标识进入参数受校验的只读诊断。
- R2：结果显示任务状态、开始时间、耗时、来源、可读摘要和原始内容；失败、超时、取消清晰可见。
- R3：为 device.info、memory.snapshot 和本任务只读接口诊断增加 App 私有的有界历史和清理入口；最多 20 条且总量 5 MiB，达到任一上限时淘汰最旧记录，不自动过期，用户可主动清空。密码、加密、文件和外部网络等其他工作台结果不纳入本任务历史。
- R4：导出前允许预览和选择包含的快照/结果，沿用系统文件选择器，不自动上传。

## Acceptance Criteria

- [x] 可从接口详情执行任务并查看带接口上下文的结果，不需再次输入接口名。Flutter 路由/参数锁定/结果展示由 `observatory_test.dart` 和 `interface_diagnostic_test.dart` 覆盖。
- [x] 重启后能查看最多 20 条/5 MiB 的只读信息任务历史；满额淘汰最旧记录，用户可主动清理；失败/超时/取消不伪装为成功。Android instrumentation 覆盖容量淘汰和状态保留，应用强制停止再启动后可见成功与失败记录，手动清理后页面为空。
- [x] 导出只含所选内容，取消文件选择不写文件，含来源和时间。SAF 读回确认仅含所选的一条历史记录及其来源/时间；另一唯一文件名取消后不存在。
- [x] 新路径保持 App-only，Root/Vector/PTY 权限和生命周期代码未变；Flutter 与授权设备的相关验证通过。正常启动时按用户授权执行既有 Root 自动恢复；未运行 Root 仪器测试。

## Out of Scope

- 不提供任意 Shell 命令入口、远程服务或后台自动运行。
- 不在本任务扩展应用、进程、日志等完整对象图谱。
