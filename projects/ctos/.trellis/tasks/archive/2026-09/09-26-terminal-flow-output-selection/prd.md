# 终端入口、输入与输出选择优化

## Goal

让手机终端从选择会话到执行命令、回看和复制输出都有清楚且可靠的操作路径。

## Background

- 当前终端页同时显示可接收键盘输入的 `TerminalView` 和底部 `TextField`；`TerminalView` 的键盘事件直接写入 PTY，底部提交又单独写入 PTY（`lib/main.dart:108,1275-1362`）。用户报告上方唤起键盘后回车或文字输入不可靠。
- 现有顶栏以两个小按钮启动 App/Root 会话，快捷栏另含 `ip addr`、`ss`、`id` 三条预设命令（`lib/main.dart:1275-1340`）。
- 原生 `terminalStart`、`terminalWrite`、`terminalResize`、`terminalStop` 已提供 App/Root PTY 生命周期；当前在线设备为 `192.168.9.9:45075`（PLR110），只确认设备在线，尚未验收新界面。

## Requirements

- R1：进入未连接的终端页时，直接显示“应用 Shell”和“Root PTY”两个清晰的 item 入口供用户选择。Root 不可用时给出可理解的状态；已连接时显示当前模式及明确的关闭/换用入口。
- R2：终端显示区仅供查看和滚动，不再取得软键盘或发送键盘输入。底部命令输入框是唯一文本入口，并可见当前正在编辑的完整命令；输入实时送往当前 Shell，由上方只读区域显示 Shell 回显、补全和执行结果。Tab 仍由 Shell 处理，其补全后的命令行须同步到下方输入框（例如 Shell 将前缀补全为 `id` 时，上下两处都显示 `id`），后续输入、退格和回车继续作用于同一 Shell 行。输入控件请求普通文本键盘，不使用密码、Secure keyboard 或其他特殊输入类型。
- R3：快捷按钮只保留 `Ctrl-C`、`Tab`、`Esc`、`↑`、`↓`；移除 `ip addr`、`ss`、`id` 预设命令。Tab 必须触发当前 Shell 的自动补全；↑/↓浏览本次 PTY 会话由底部输入框提交的命令，并通过同一 PTY 输入路径恢复和编辑，避免设备 Shell 的长行历史重绘把命令截断。Ctrl-C/Esc 保留 PTY 控制语义。
- R4：将“选择输出”入口放在会话顶部“换用”右侧；点击后打开独立子页面，显示打开时终端输出区中可回看的文本；用户可滚动、长按选择和复制，返回后继续使用原会话。
- R5：保留现有 App/Root PTY、窗口尺寸更新、会话结束检测和 Ctrl-C 能力；不扩大 Root 授权范围。
- R6：终端输入框不显示“输入命令”或“实时输入、回显在上方”等提示说明。同步清理工作台、设备、网络、命令和连接页里同类泛化或重复的标题/副标题；保留权限、数据来源、采样范围和失败状态等影响判断的必要信息。

## Acceptance Criteria

- [x] 首次进入终端或关闭会话后可见两个入口；选择后进入相应会话，当前模式明确，Root 不可用时不会误启动。
- [x] 点击或拖动输出区不会唤起软键盘；底部输入框可见当前输入的文字，输入、退格、粘贴、中文组合输入和回车可靠送往 PTY，发送按钮与键盘完成键不重复提交；设备上显示普通文本键盘。当前包实测 Tab 后继续编辑和键盘发送；其他输入法细节的设备证据属于前一构建，见验证记录。
- [x] 快捷栏恰好只有指定五个按钮，并按最终确定的语义在 App/Root 会话中工作。
- [x] 选择输出页包含当前可回看的输出文本，支持滚动、选择、复制；返回时会话仍可操作。
- [x] Flutter 静态分析、相关测试及授权设备的软键盘/会话/输出选择定向验证完成，无法执行的检查如实记录。
- [x] 终端输入框没有提示文字，“选择输出”位于顶部“换用”右侧；上述页面不再出现演示式说明，必要的权限、来源和受限状态仍能在相应页面找到。

## Out of Scope

- 多会话、持久化历史、后台终端、命令脚本、远程 Shell 和完整屏幕交互程序的键盘控制。
