# 终端入口、输入与输出选择：技术设计

## 边界与状态

- 本子任务只改终端交互；现有父任务中的全局视觉与连接展示仍独立规划。保留 Flutter → `ctos/native` → JNI PTY 的执行边界，不改 Root 授权策略或 PTY 协议。
- 未连接态直接展示两个大 item：“应用 Shell”和“Root PTY”。Root 不可用时 item 解释原因并不可启动。会话态展示模式、关闭/换用会话动作、只读终端、五个 PTY 快捷键和底部输入。退出/关闭后回到入口；换用前先结束原会话，不维持并发会话。启动与关闭中的状态要防重入。
- 保持一个 `Terminal(maxLines: 3000)` 与 EventChannel 订阅。保留尺寸回调，且只在会话可用时向 native 发送。新会话开始时清晰分隔输出，避免把旧会话误当当前会话；仍可回看保留的输出，直到缓冲区淘汰。

## 单一输入路径

- `TerminalView(readOnly: true)` 仅绘制、滚动和调整尺寸，不打开 IME，也不将按键转发给 PTY。原 `terminal.onOutput` 只处理 xterm 自身的设备响应，不承载用户键入。
- 底部实现一个可聚焦的普通文本输入表面，显示当前正在编辑的命令。它将 IME 的已提交编辑实时同步到 `terminalWrite`，空输入上的退格发送 Delete/Backspace 序列，软键盘“发送/回车”与界面发送按钮向 PTY 发送一次 Enter。中文等组合输入须处理输入法先提交拼音、再以候选汉字替换的编辑序列，避免丢字或重复字。命令行同时由 Shell 在上方只读终端回显。Tab 发送给 Shell；收到回显后将 Shell 当前可编辑行同步到下方输入框，不向 PTY 回发这次补全文本。↑/↓浏览当前会话从底部输入框提交的最近命令，用同一差量编辑路径写回 PTY，保留用户尚未执行的草稿。Ctrl-C 清空已取消的命令。若 Shell 补全不能可靠解析，不能让输入框显示与 Shell 行不一致的旧草稿，须显式提示并清除本地过时草稿。
- 输入配置采用 `TextInputType.text`、普通文本动作、非密码输入，并避免 xterm 内部的 `emailAddress`/`enableSuggestions: false` 输入配置。关闭自动改写以保护命令内容；允许普通键盘候选栏。具体 OEM 键盘外观以设备实测为准。
- 输入框不显示标签或提示文字；进入终端的会话选择页已足以解释模式，不再向 xterm 输出欢迎/操作说明。会话顶部“换用”右侧放置“选择输出”，避免占据输入区上方的独立操作行。工作台、设备、网络、命令和连接页的静态文案按同一原则收敛：删重复的流程解释，保留会改变用户判断的权限、来源、采样和失败信息。
- Ctrl-C、Tab、Esc 分别向 PTY 发送 `0x03`、`0x09`、`0x1b`；↑/↓从当前会话最多 100 条已提交命令中切换，用现有文本差量编辑发送 PTY 退格和文字。Android 应用 Shell 在这台设备上用原始箭头键召回较长命令时会发出被截断的重绘行；会话输入历史避开该故障。所有输入都经同一个会话写入队列，避免异步方法调用交错。会话未就绪时不发送。按快捷键后让底部输入继续可聚焦，不让输出视图抢焦点。

## 输出选择页

- 点击“选择输出”时，从 `Terminal.lines` 复制一份当前活动缓冲区的渲染后文本，最多 3000 行；软换行按 `isWrapped` 合并，硬换行保留。原始 ANSI 控制序列不作为可选择文本。视图显示快照而非持续追加，保证用户选择和滚动位置稳定；页面标题注明“当前输出”。
- 新页面使用可滚动的选择控件，支持长按选取、复制和系统文本选择工具；关闭后原 PTY 会话继续运行。若缓冲区为空，显示明确空态。内容只在本地内存，任务不新增历史存储或自动导出。

## 验证与限制

- 组件测试覆盖入口/禁用状态、只读终端、五个快捷键、底部输入调用次数、输出快照和返回后的会话保留。输入处理须覆盖组合输入、退格、粘贴、空文本与重复提交。
- 在显式设备 `192.168.9.9:45075` 上检查普通键盘、Tab 补全、上下历史、Ctrl-C、软键盘回车、输出选择/复制和 Root 可用时的会话。设备在线仅是当前状态，验证时需重新确认身份。Android 11 开发板不在线则列为未验收。
- 由于普通文本键盘由设备 IME 实现，应用只能请求输入类型，不能保证特定厂商键盘的外观。若 PLR110 仍显示 Secure keyboard，需在实现阶段检查实际 Flutter IME 配置和设备策略，不把“普通文本类型”当成实机通过。

## 回退点

- Flutter 终端页面和输入组件可单独回退；不需迁移原生会话或存储数据。若输入组件在目标设备无法稳定处理 IME，保持旧版 APK 与当前代码可恢复，不发布未经验证的实时输入路径。
