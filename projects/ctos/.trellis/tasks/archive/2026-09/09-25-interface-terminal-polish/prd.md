# 界面与终端可用性整理

## Goal

统一 ctOS 的视觉层级与信息密度，使连接数据和终端在窄屏、软键盘和大字号下仍可读、可操作。

## Background

- `lib/main.dart` 自定义面板与 `lib/device_page.dart` 的默认 Card 并存；工作台之外的阅读页未共享统一最大宽度；终端快捷栏始终展开，输出快照页目前仅支持选择和手动复制。
- 依赖兄弟任务 `09-25-trustworthy-state-workbench` 的视觉基线；开始本任务前复核其已交付 token 和组件。
- 连接页目前已有结构化条目、过滤、部分/过期状态及可展开原始输出；已归档子任务 `09-26-terminal-flow-output-selection` 已提供独立输出选择/复制页。本任务补齐视觉宽度、快捷栏折叠和该快照页的搜索/复制入口，不重做连接解析或输出选择。

## Requirements

- R1：统一表面、状态色、字级与间距，保留现有深色/薄荷色身份；大屏控制阅读宽度。
- R2：连接行先展示状态、地址、UID/应用，原始 `ss` 输出仍可查看；保持过滤和部分结果提示。
- R3：终端快捷键栏可收起，当前 App/Root 会话清晰，提供输出搜索/复制入口，保留 PTY 控制能力。
- R4：图标动作有可访问名称，触控目标、缩放字号、软键盘和安全区行为可验收。

## Acceptance Criteria

- [x] 工作台、概览、信息页与设备卡片沿用统一深色/薄荷色表面；手机保持单列，大屏阅读内容居中且宽度不超过 840 dp；终端画布保留可用横向宽度；320 dp 窄屏及 1.5 倍系统字号无布局异常。宽屏、320 dp 带键盘与 1.5 倍字号由 widget 测试覆盖。
- [x] 连接仍按现有条件检索；结构化行来自同一连接快照，原始输出可展开；部分、过期和刷新失败状态仍能辨认。现有连接状态回归通过全量 Flutter 测试。
- [x] 终端快捷栏可展开/收起且保留 Ctrl-C、Tab、Esc、上/下五个控制；会话切换、唯一输入路径和既有输出选择不回归；快照搜索可定位匹配并显示数量，复制全部输出与当前快照逐字一致。设备验收与精确剪贴板 payload widget 断言通过。
- [x] 图标动作有可访问名称，新增及调整的触控目标至少 48 dp；软键盘、系统字号缩放与安全区下主要输入/操作可见。`TARGET-BOARD` 上 App/Root PTY、普通键盘、快捷栏、Ctrl-C、输出搜索/复制与返回存活均通过，设备和 APK 身份见 `check.md`。
- [x] `./hako flutter analyze`、`./hako flutter test` 和 `./hako current` 成功；本任务授权设备的实机回归单独记录于 `check.md` 与 `design/verification.md`。

## Out of Scope

- 不在本任务引入后台终端、多会话持久化、命令脚本或网络服务。
