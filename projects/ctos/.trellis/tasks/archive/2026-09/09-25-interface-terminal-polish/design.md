# 技术设计：界面与终端可用性整理

## 目标与边界

统一可见页面的表面和阅读节奏，降低大屏信息过宽、终端控件占高以及长输出难找的问题。变更限于 Flutter UI 和 widget tests；不改连接采集、Root 能力、Java/JNI PTY 协议、依赖或持久化。

## 设计决定

1. **沿用现有视觉身份。** 使用 `CtosApp` 的背景 `#0b1018`、面板 `#151e2b`、薄荷色 `#65efb4` 及 Material 3。为 `Card` 设统一面板色、无额外色调叠层、圆角和外边距；将 `main.dart` 的自定义卡片改为使用同一主题，消除与 `DevicePage` 默认卡片的底色差异。辅助状态保留文字，不单靠颜色。
2. **限制阅读列，不缩窄终端。** 概览与信息页共用居中的 840 dp 最大内容宽度；工作台沿用其既有 840 dp 约束。交互 PTY 画布保持所在页面的完整宽度以增加可见列数；“当前输出”阅读页限制正文最大宽度并居中。窄屏沿用单列和现有滚动结构。
3. **快捷栏默认展开，可手动收起。** 一次会话默认显示全部五个现有控制，新增带语义名称、至少 48 dp 高的展开/收起按钮。用 `Wrap` 适应可用宽度，不用横向滚动作为唯一发现方式。收起控制条不改变 PTY、输入或焦点状态；换会话后恢复默认展开。
4. **输出搜索只作用于当前快照。** `TerminalOutputPage` 保留 point-in-time 字符串及选择能力；增加不区分大小写的本地搜索、高亮和匹配数，以及“复制全部输出”操作。搜索不写 PTY，不刷新快照，不保存历史；复制精确复制页面收到的原字符串，并在完成后给出短提示。空输出时搜索/复制不可用或显示空状态。
5. **可访问与安全区行为。** 为图标操作设置 tooltip/语义标签；保留 48 dp 交互目标；不使用固定高度裁切字号；输出页、输入框和导航继续处在现有 `SafeArea` / Scaffold inset 管理内。设备字段可换行，连接地址保留选择/复制能力。

## 数据流与组件边界

- 连接视图继续以 `ConnectionReport`、`ConnectionSnapshotState` 和现有 `ss` 原始文本为唯一来源；仅共享页面宽度/主题约束，不另建一份解析结果。
- 终端保持 `TerminalView(readOnly: true)` 加底部唯一 `TerminalCommandInput`。快捷栏折叠只影响控件展示；控制按键仍走当前序列化 PTY 写入路径。
- 输出页接收 `terminalOutputSnapshot(terminal)` 的不可变快照；搜索、高亮和剪贴板行为由输出页局部状态拥有，离开页面后释放。

## 兼容、取舍与回退

- 不增加依赖、路由或原生 API；App/Root PTY 生命周期和返回行为不变。
- 共享 `CardTheme` 会影响既有 `Card`，需在窄屏/大字号和页面间一致性测试中检查间距回归。
- 将快捷控件改为 `Wrap` 会改变窄屏上的纵向高度，但避免必须横向滚动才能找到按键。默认展开保持已有发现性，用户可主动收起腾出软键盘空间。
- 如布局或终端交互回归，回退范围为本任务涉及的 Flutter 主题/页面/widget 测试文件；没有数据迁移或设备持久状态需要恢复。
