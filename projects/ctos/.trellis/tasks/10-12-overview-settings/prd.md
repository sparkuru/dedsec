# 概览整合与设置面板迁移

## 目标
将信息查询统一到概览，将全局数据导出和公共秘密库管理集中到设置。

## 已确认背景
- `lib/main.dart` 当前四入口为概览、信息、工作台、终端；信息含设备、网络、接口、连接。
- 顶部全局导出调用 `openExport`，打开逐项选择/预览/SAF 保存的 `ExportPreviewPage`。
- `lib/workbench.dart` 的秘密库设置入口打开 `SecretVaultSettingsPage`，已包含创建、解锁、改口令、快捷认证、后台时间、备份导出/导入及恢复处理。
- 用户明确要求新建 task、设为 current 并开始完成；该指令同时授权规划和实施，无需再次确认阶段切换。

## 要求
- R1：概览保留现有设备摘要、内存和电量，删除网络现场和能力与恢复，将原信息分类及完整内容直接放到摘要下方。
- R2：删除独立信息主入口；主导航顺序为概览、工作台、终端、设置，窄屏与宽屏一致。
- R3：所有主面板右上角不再显示导出按钮；设置中的数据导出复用原快照逐项选择、预览和保存流程，包括原先的禁用条件及取消反馈。
- R4：秘密库设置整体迁到设置/安全，移除工作台旧入口并更新相关文案；全部已有操作、状态、错误和恢复能力保留。
- R5：保持现有采集权限和生命周期；网络分类保留手动 Root 授权。概览连接分类进入/恢复前台刷新，工作台和设置不因导航调整额外轮询网络。
- R6：四个新主入口沿用双返回退出；安全、导出及其他二级页面沿用普通返回。
- R7（用户截图追加）：设备/网络/接口/连接切换占满概览内容宽度，选项文字居中，大字窄屏仍可操作。
- R8：移除全局APP可用标识和内容区Root状态块；ctOS标题紧邻小信息按钮表示Root，在线绿色、未连接/授权中黄色，点按可读明确状态和已有失败原因。
- R9：移除终端会话选择页绿色“TERMINAL / 交互”眉标题，保留主标题和操作。
- R10：设置/安全解锁时，已登记快捷直接尝试快捷，无登记直接主口令。快捷失败后才显示取消/使用主口令/快捷解锁选择；选择快捷可重新尝试，失败不自动重复系统认证，管理改口令/关闭快捷/备份认证继续要求真实口令。
- R11（最终截图追加）：去掉概览摘要的绿色DEVICE眉标题和Android版本/运行时间副标题，保留设备名称、内存/电量及详细设备信息。
- R12：网络、接口、连接副标题参照设备页改为静态内容范围描述；接口计数/采集来源保留为独立元数据，不再混入副标题。

## 验收标准
- AC1（R1/R2）：导航只有新四入口；概览摘要下能切换设备、网络、接口、连接并查看完整内容，不出现删除区块。
- AC2（R3）：四主面板顶部无导出按钮；设置可打开原数据选择页，所选内容及取消/保存行为保持。
- AC3（R4）：设置/安全能够打开完整秘密库管理页面；工作台无旧入口；既有秘密库交互测试通过。
- AC4（R5/R6）：连接进入及前台刷新、接口搜索/诊断回跳、终端会话保留、主入口返回及二级页返回无回归。
- AC5：320/375 dp、横屏、1200 dp、2倍文字及减少动画检查无溢出，相关及全量 Flutter 测试、analyze、格式检查通过；设计与验证记录同步。
- AC6（R7–R9）：分类控件左右对齐概览内容，均分并居中，Root信息按钮紧邻ctOS且可读在线/离线状态，APP标识及终端绿色眉标题不存在。
- AC7（R10）：已登记/未登记/系统不可用/快捷成功或失败/重试/主口令回退/取消/路由销毁与迟到结果分别通过；不在首次成功快捷前弹方式选择，未登记时不请求快捷。完成解锁仍检查新鲜host状态、代次及当前路由；原敏感保护和一次性请求边界保留。
- AC8（R11/R12）：概览只有设备名称及指标摘要；DEVICE/Android运行摘要行不存在。设备/网络/接口/连接均为标题+范围描述，动态来源/计数/时间仍位于数据区。新版本地检查、渲染和开发板可见布局通过后，提交当前task全部相关改动。

## 范围外
不新增安全算法、秘密库功能或权限，不推进 TOTP/SSH 任务，不改变 Android host 协议，不替换 dist。初轮仅本地；用户随后授权“你可以自行连接上去，自行验收”，允许当前开发板覆盖安装和本任务验收，不更改系统锁屏或真实库内容。最后用户明确“不建task；在当前task一起完成；完成后提交”，授权本任务全部相关改动提交并正常收尾；不重复请求提交许可，不push。
