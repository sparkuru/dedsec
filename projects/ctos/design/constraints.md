# ctOS 项目约束

日期：2026-09-24。与规划配套，后续实现和验证以本文件为边界；明确的新用户指令优先。

## 工作范围与信息归档

- 项目工作限定于 `projects/ctos`，不顺带修改其他项目、仓库顶层配置或公共依赖目录。
- `design/` 是项目各种信息的统一落点，维护方式见 [索引](README.md)。项目根 README 只承担简介和使用入口，AGENTS.md 承担执行约定。
- 保留已有用户修改；不将文档任务扩展为代码修改、安装、重启或设备配置变更。
- 临时产物优先使用项目内被忽略的构建或临时位置；不把敏感原始日志、凭据和签名密钥提交到仓库。引用历史外部证据时说明其位置，不推定仍存在。

## 产品与执行边界

- 首先服务 Android 本机的信息查看和用户主动操作。外部调用、远程服务与自动化能力需要独立设计。
- App API、Root 采集与 Root PTY 是不同权限与生命周期边界；界面不得以一个笼统的“已授权”掩盖差异。ctOS 不依赖 Vector，决定见 [Root-only](decisions/2026-09-26-root-only.md)。
- 首次启动可向设备 Root 管理器申请一次授权；授予后保存应用内自动启动标记，后续启动及覆盖安装恢复采集会话。拒绝、失败或会话超时后不自动反复申请，需用户在概览手动重试。Root 采集复用已授权会话。
- 任意 Shell 命令由用户主动启动的终端或明确设计的脚本功能承载。结构化命令校验参数，不把未校验的输入拼接为 Shell 指令。
- 不提供跨应用广播命令或提权入口；Root 固定查询与用户主动终端操作分开。
- 新增工具的Root需求必须在host-owned执行上下文显式声明，并通过ctOS拥有的、限定操作的adapter检查和代理。能力声明不代表授权，不提供任意Root Shell/文件句柄；无Root、拒绝或失败只限制所需操作，不能阻止App基础路径使用。本轮HFTP仅网络中继获授权，Python HTTP/文件/SAF仍为App权限；不修改VPN/Clash/路由/防火墙/SELinux。
- 修改系统状态的结构化操作应展示目标、参数和影响；破坏性或不可逆操作在执行前要求明确确认。

## 数据与采样

- 每类信息标明来源、采集时间与状态，区分无权限、不支持、失败和真实零值。
- 无 Root 时提供可用的基础路径，缺少增强能力不能导致整个应用不可用。
- 静态信息按需读取；动态指标仅对需要的页面或任务采样；日志由用户主动开启；昂贵查询手动触发。
- 采集与命令执行不阻塞 UI 或系统关键线程。历史、日志、命令输出和并发均设上限，支持超时与资源回收。
- 数据源切换、计数回退及对象消失时重建基线。网络接口累计值不冒充今日流量；VPN 与物理接口不直接求和。
- 默认本地处理，不自动上传。导出内容、历史保留和清理行为对用户可见。

## 终端与任务生命周期

- 结构化任务与交互 PTY 分开管理，明确运行、完成、失败、取消及超时状态。
- 保留 PTY 的输入、尺寸调整、UTF-8 解码、Ctrl-C 与子进程回收能力。
- 现有版本的生命周期以当前架构和源码为准；新增后台任务前单独设计存活条件、用户可见状态和停止入口，不默认常驻。
- 不在新增信息轮询时重新引入重复 su 授权提示。

## 实现与验收

- 沿用 Flutter、Java、JNI PTY 和 Root 会话，按职责渐进拆分。引入新依赖时同步记录来源、版本和用途。
- 检查与变更对应：文档检查链接和事实一致性；代码按影响执行静态检查、相关测试及必要的实机回归。
- 开发板连接入口：`adb connect "$BOARD_ADB_SERIAL"`，执行前将 `BOARD_ADB_SERIAL` 设置为当前授权并确认的开发板地址。连接后确认设备身份，后续命令显式指定该设备，避免误操作其他在线设备。
- 安装、Root 授权、Vector 配置和重启按当前任务授权范围执行；历史验收中的授权不是本轮操作授权。
- 不修改其他应用或系统模块的配置来使 ctOS 验收通过。
- Android 11 开发板、Android 16 手机、Permissive 与 Enforcing 的结论分别记录，不能互相代替。
- 验证记录包含日期、版本或产物标识、设备环境、实际结果和未验证项；未运行的检查不能写成通过。
- App展示页面只保留操作、权限、状态和失败恢复所需文案，不堆积demo介绍、实现进度或架构说明；详细契约维护在design/spec。具体审阅例子见[工作台前端spec](../.trellis/spec/frontend/workbench.md)。

## Portable 与 SDK（2026-09-26）

APK 内置包按显式清单挂载到应用私有目录；原生程序由 APK 的原生目录执行，ZIP 不运行安装脚本。第一版只加载编译时可信内容，不导入外部 ZIP。工作台 Python 子进程始终使用 App 权限、单任务、有界输入输出和 15 秒超时；后台、取消或页面退出后回收。终端 python3 使用用户主动选择的 App/Root PTY 权限。扩展契约及未实现项见 [portable-workbench.md](portable-workbench.md)。

## 工具与文件服务（2026-09-26）

五项工具范围由当前用户选择限定。工作台文件通过 App 私有 token 与 SAF 流转；密码不自动持久化，加解密不删除源。HFTP 后台持续运行是用户明确要求，必须经独立可见前台服务手动启动、无自动重启。2026-09-27 图片反馈明确授权 App 默认局域网/7888/免登录、可设置上传大小及选择本机目录；仅扩展文件服务，不增加远程命令。目录必须经系统 SAF read/write 授权，不使用 Root/全文件权限，不覆盖或清理用户已有文件。APK 内置依赖、项目私有构建缓存和 ${EVIDENCE_DIR} 验证环境不写全局 Python/PATH/HOME 或系统挂载。详见 [工具设计](portable-tools.md)。
