# Commit and task archive policy

The project is a subtree of a larger Git repository. Before any stage, commit or archive commit, inspect the enclosing repository's status and index, preserve unrelated changes, and stage only an explicit reviewed list of project paths within existing user authorization. Do not force-add ignored files or stage `.codex/`, `.agents/`, credentials, runtime pointers, generated build outputs, or the ignored `archive/` checkout. A verified unchanged Trellis 0.6.17 baseline and its exact notice may be included only after provenance review; it remains upstream material.

For a Codex-assisted task, use exactly one `Co-authored-by: OpenAI Codex <codex@openai.com>` trailer in that task's successful archive commit, not every work or journal commit. The installed `python3 .trellis/scripts/task.py archive <task> --no-commit` supports moving a task without its default auto-commit. Once archive and commit are authorized, verify the move and task status, prepare a message in a temporary file, stage only the reviewed archive and related project paths, and create the explicit archive commit. Inspect the resulting paths and message; do not amend history or make an empty attribution commit.

If a move succeeds but commit fails, inspect task location, index and history before retrying only the remaining commit; never archive twice. If provenance, notice, commit authority, an existing staged change, or archive state is unresolved, report the exact blocker. `add_session.py` may auto-commit by default; do not call it as a harmless logging command without checking its arguments and authorization.
